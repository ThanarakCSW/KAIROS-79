# 🤖 KAIROS-79 MT5 Bridge Expert Advisor (EA)
### คู่มือการติดตั้งและใช้งาน EA บน Windows PC / Windows VPS

ไฟล์ Expert Advisor นี้ (`KAIROS79_Bridge.mq5`) ทำหน้าที่เป็น **แขนกลส่งคำสั่ง (Execution Muscle)** เชื่อมต่อระหว่างโปรแกรม **MetaTrader 5 (MT5)** บน Windows PC หรือ Windows VPS กับ **ระบบวิเคราะห์ AI KAIROS-79** บนเว็บเบราว์เซอร์

---

## 🌟 คุณสมบัติเด่น (Features)
1. **Auto-Trading Master Switch (Auto ON/OFF):** ควบคุมการเปิด/ปิด ออเดอร์อัตโนมัติได้จากหน้าเว็บ KAIROS-79 โดยตรง
2. **Real-time Live Telemetry:** ส่งข้อมูล Balance, Equity, Margin, Free Margin, Floating PnL และสเปรดจริงจาก MT5 ขึ้นไปแสดงผลบนหน้าเว็บแบบสดๆ
3. **Execution Synchronization:** รับคำสั่ง `BUY`, `SELL`, `BUY LIMIT`, `SELL LIMIT` จากระบบ AI พร้อมส่งเลข Ticket จริงและราคาเข้าจริงกลับมาอัปเดตบนหน้าเว็บ
4. **Autonomous Multi-Order Support:** รองรับการเปิดไม้แก้ (DCA) หรือไม้ขยายกำไร (Scale-in) อัตโนมัติตามกลยุทธ์ KAIROS-79
5. **Web Override Close:** สามารถกดปุ่ม **"✓ จบการเทรดไม้นี้"** หรือ **"✓ จบการเทรดทุกไม้"** บนหน้าเว็บเพื่อสั่งปิด Position จริงใน MT5 ทันที
6. **Safety Guardrails:**
   - **Magic Number `797979`:** ป้องกันไม่ให้ EA ไปยุ่งกับออเดอร์มืออื่นๆ ในพอร์ต
   - **Spread Guard:** ปฏิเสธการเข้าออเดอร์หากสเปรดถ่างเกินกำหนด (เช่น ช่วงข่าวกล่องแดงแรง)
   - **Idempotency:** ป้องกันการเปิดออเดอร์ซ้ำซ้อนแม้สัญญาณหลุด
   - **Hardware Millisecond Heartbeat:** ใช้ Monotonic Clock (`GetTickCount64`) ในการส่ง Heartbeat ทำให้ระบบตรวจจับสถานะเชื่อมต่อตลอดเวลา แม้ตลาดปิดหรือไม่มี Tick วิ่ง
   - **Instant Manual Dispatch Support:** รองรับการกดปุ่ม **"🚀 ส่งเข้า MT5 ทันที"** จากหน้าเว็บเพื่อสั่งเปิดออเดอร์เข้าพอร์ตทันทีแม้ปิดโหมด Auto-Trading

## 🛠️ ขั้นตอนการติดตั้งบน Windows PC / Windows VPS

### ขั้นตอนที่ 1: คัดลอกไฟล์ EA ลงใน MetaTrader 5
1. เปิดโปรแกรม **MetaTrader 5 (MT5)** บน Windows
2. ไปที่เมนูด้านบน คลิก **File** -> **Open Data Folder** (หรือกด `Ctrl+Shift+D`)
3. ดับเบิ้ลคลิกเข้าโฟลเดอร์ **MQL5** -> **Experts**
4. นำไฟล์ `KAIROS79_Bridge.mq5` ไปวางในโฟลเดอร์นี้

### ขั้นตอนที่ 2: คอมไพล์ (Compile) ไฟล์ใน MetaEditor
1. กลับมาที่หน้าต่าง MT5 กดปุ่ม **F4** (หรือคลิกไอคอน MetaEditor บนแถบเครื่องมือ) เพื่อเปิดโปรแกรม **MetaEditor 5**
2. ในแถบ Navigator ด้านซ้าย ให้เปิดโฟลเดอร์ **Experts** และดับเบิ้ลคลิกเปิดไฟล์ `KAIROS79_Bridge.mq5`
3. กดปุ่ม **Compile** (หรือกดแป้นพิมพ์ **F7**)
4. ตรวจสอบหน้าต่างด้านล่าง ต้องขึ้นว่า:
   ```
   0 errors, 0 warnings
   ```
   *(จะได้ไฟล์ `KAIROS79_Bridge.ex5` พร้อมใช้งานทันที)*

### ขั้นตอนที่ 3: เปิดสิทธิ์ WebRequest ใน MT5 (สำคัญมาก ⚠️)
เพื่อให้ EA สามารถส่งข้อมูลคุยกับ KAIROS-79 ผ่าน HTTP ได้:
1. ในโปรแกรม MT5 ไปที่เมนู **Tools** -> **Options** (หรือกด `Ctrl+O`)
2. คลิกที่แท็บ **Expert Advisors**
3. ติ๊กถูกที่:
   - `[✓] Allow Algo Trading`
   - `[✓] Allow WebRequest for listed URL:`
4. ดับเบิ้ลคลิกที่ช่องสีขาวด้านล่าง (เครื่องหมาย `+`) แล้วพิมพ์ URL ของเซิร์ฟเวอร์ KAIROS-79:
   - หากรัน KAIROS-79 บนเครื่องเดียวกัน: พิมพ์ `http://127.0.0.1:8000` และ `http://localhost:8000`
   - หาก KAIROS-79 อยู่บนเครื่องอื่น หรือ VPS: ให้ใส่ IP หรือโดเมน เช่น `http://192.168.1.100:8000` หรือ `http://YOUR-VPS-IP:8000`
5. กดปุ่ม **OK**

### ขั้นตอนที่ 4: ลาก EA ลงบนกราฟทองคำ (XAUUSD)
1. เปิดกราฟ **XAUUSD** (ทองคำ) ใน MT5 ไทม์เฟรมใดก็ได้ (แนะนำ M5)
2. ในหน้าต่าง Navigator (ด้านซ้ายของ MT5) ขยายเมนู **Expert Advisors**
3. คลิกขวาลาก `KAIROS79_Bridge` มาวางบนกราฟ
4. ในหน้าต่างตั้งค่า:
   - แท็บ **Common**: ติ๊กถูกที่ `[✓] Allow Algo Trading`
   - แท็บ **Inputs**:
     - `InpServerUrl`: ใส่ URL ของ KAIROS-79 (ค่าเริ่มต้น `http://127.0.0.1:8000`)
     - `InpMagicNumber`: `797979` (เลขเฉพาะสำหรับ KAIROS-79)
     - `InpMaxSpreadPoints`: `50.0` (สเปรดสูงสุดที่ยอมให้เข้า)
5. กดปุ่ม **OK**
6. ตรวจสอบปุ่ม **Algo Trading** บนแถบเครื่องมือ MT5 ด้านบน ต้องเป็นสีเขียว (Play) ▶️

## 🖥️ การดูสถานะและการควบคุมผ่านหน้าเว็บ KAIROS-79
1. เมื่อ EA เริ่มทำงาน แถบด้านบนของหน้าเว็บจะขึ้นสถานะ:
   `🟢 MT5: #เลขที่พอร์ต (ชื่อโบรกเกอร์) • Bal $X,XXX | Eq $X,XXX`
2. **สวิตช์ Auto-Trading:**
   - กดปุ่ม `⚡ AUTO-TRADING: ON` เพื่อให้ระบบออกออเดอร์อัตโนมัติเมื่อสัญญาณผ่านเกณฑ์
   - กดปุ่ม `⏸️ AUTO-TRADING: OFF` เพื่อหยุดการออกออเดอร์อัตโนมัติชั่วคราว (แต่ยังมอนิเตอร์พอร์ตและรับแจ้งเตือนได้ตามปกติ)
3. เมื่อมีออเดอร์เปิดอยู่ หากต้องการจบไม้ สามารถกด **"✓ จบการเทรดไม้นี้"** จากหน้าเว็บ คำสั่งจะส่งตรงไปปิด Position ใน MT5 ทันที
4. สามารถกดปุ่ม **"🚀 ส่งเข้า MT5 ทันที"** บนหน้าโพยคำสั่ง เพื่อสั่งส่งออเดอร์เข้า MT5 โดยตรงแบบ Instant Dispatch

## ❓ ปัญหาที่พบบ่อย (Troubleshooting)

### 1. ใน MT5 ขึ้น Online แต่บนเว็บขึ้น "MT5: Offline"
- **สาเหตุ:** พอร์ตหรือ IP ไม่ตรงกัน (เช่น เว็บบน Mac/VPS แต่ MT5 ชี้ไปที่ `127.0.0.1` ของเครื่องตัวเอง) หรือติด Firewall
- **วิธีแก้:**
  1. ดู URL ที่หน้าคอนโซลของ KAIROS-79 เมื่อรันเซิร์ฟเวอร์ จะแสดง `http://<LAN_IP>:8000`
  2. นำ URL นั้นไปเพิ่มใน MT5: **Tools** -> **Options** -> **Expert Advisors** -> **Allow WebRequest for listed URL**
  3. ดับเบิ้ลคลิกหน้ากราฟ MT5 ที่ EA รันอยู่ แก้ไขช่อง `InpServerUrl` ให้ตรงกับ URL นั้น

### 2. สัญญาณขึ้นบนเว็บแล้ว แต่ใน MT5 ไม่มีออเดอร์เปิด
- **สาเหตุ 1:** สวิตช์ `⚡ AUTO-TRADING` บนหน้าเว็บยังเป็น `OFF` (สามารถกดเปิดเป็น `ON` หรือกดปุ่ม **"🚀 ส่งเข้า MT5 ทันที"**)
- **สาเหตุ 2:** ปุ่ม **Algo Trading** บนแถบเครื่องมือของ MT5 เป็นสีแดง (ปิดอยู่) ให้คลิกให้เป็นสีเขียว ▶️
- **สาเหตุ 3:** ตรวจสอบแท็บ Experts ด้านล่างของ MT5 หากขึ้นข้อความแจ้งเตือน เช่น Spread สูงเกินกำหนด หรือติดข้อจำกัดของโบรกเกอร์
